# AVASAG Corpus subset for MMS Player

This folder contains a subset of the AVASAG corpus, developed within the AVASAG project (https://avasag.de) between 2021 and 2023.
The corpus is being used and extended within the BIGEKO project (https://www.interaktive-technologien.de/projekte/bigeko).

The Corpus is not fully public (yet), and no scientific publication is available (yet).
This subset is meant to be used only in conjunction with the MMS Player, Sign Language avatar animation synthesis research prototype: https://github.com/DFKI-SignLanguage/MMS-Player

This subset contains only the glosses of the corpus, and only the skeletal motion data (extracted from captured BVH files). Facial animation data will follow.
